# mdEngine

This is Assigment 1 for the "Graphics Programming" course at HCMUT.

## Building

### Dependencies

- CMake >= 4.1
- git

### Clone

```bash
git clone https://github.com/Reimnop/mdEngine.git --recursive
```

### Initialize CMake

```bash
mkdir build
cd build
cmake ..
```

### Build

```bash
cmake --build . --config Release
```

### Run

```bash
./mdEngine
```
